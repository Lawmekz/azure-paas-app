=====================================================

STUDENT: AJAGU NNAEMEKA LAWRENCE
LIVE URL: https://paas-assessment-ajagu.azurewebsites.net

RUNTIME STACK
-------------
Node.js 22 LTS with Express.js framework.
Node.js was chosen for its lightweight footprint, fast startup time,
and excellent support on Azure App Service Linux environments.

PRICING TIER & SERVICE PLAN
----------------------------
Plan Name: paas-assessment-plan
Tier: F1 (Free Tier) — LinuxFree
Region: West Europe (eastus had quota limitations)
OS: Linux (chosen over Windows for lower cost and better Node.js performance)
CPU: Shared | Memory: 1GB | Storage: 1GB
The Free tier was selected to minimize cost for assessment purposes.
For production, B1 Basic or higher would be recommended for Always-On support.

DEPLOYMENT METHOD
-----------------
GitHub Integration via Azure Deployment Center (ExternalGit/manual integration).
Repository: https://github.com/Lawmekz/azure-paas-app
Branch: main
Every push to the main branch can trigger redeployment via sync command:
  az webapp deployment source sync --name paas-assessment-ajagu --resource-group rg-paas-assessment
Startup command configured: node app.js

ENVIRONMENT VARIABLES (Configuration Blade)
--------------------------------------------
APP_ENV=production    (set via Azure App Service Configuration)
STUDENT_NAME=AJAGU NNAEMEKA LAWRENCE (set via Azure App Service Configuration)
These are managed without code changes, demonstrating PaaS configuration best practices.

MONITORING AND DIAGNOSTICS
---------------------------
Azure App Service provides built-in monitoring via:
- Log Stream: Real-time logs accessible from Azure Portal > App Service > Log stream
- Application Insights: Can be enabled from Portal > App Service > Application Insights blade
- Metrics: CPU percentage, memory, HTTP requests visible under Portal > Metrics
- Deployment logs: Viewable under Deployment Center > Logs
To enable Application Insights:
  az monitor app-insights component create --app paas-assessment-ajagu --location westeurope --resource-group rg-paas-assessment

SCALING OPTIONS
---------------
Vertical Scaling (Scale Up): Change App Service Plan tier
  - F1 Free → B1 Basic → B2 → P1V2 Premium
  - Command: az appservice plan update --name paas-assessment-plan --resource-group rg-paas-assessment --sku B1
Horizontal Scaling (Scale Out): Add more instances
  - Available from B1 tier and above
  - Portal: App Service > Scale out > Manual or Autoscale rules
  - The Free tier (F1) supports 1 instance only

PAAS vs IAAS COMPARISON
------------------------
PaaS (Azure App Service used here):
  - No VM management or OS patching required
  - Built-in load balancing, auto-scaling, SSL
  - Deployment directly from GitHub
  - Reduced operational overhead
IaaS (Azure Virtual Machines):
  - Full control over OS and runtime
  - Requires manual configuration of Node.js, Nginx, SSL
  - Higher operational overhead

DEPLOYMENT SLOTS (Advanced Feature)
-------------------------------------
Deployment slots allow staging before production:
  - Create staging slot: az webapp deployment slot create --name paas-assessment-ajagu --resource-group rg-paas-assessment --slot staging
  - Swap to production (zero downtime): az webapp deployment slot swap --name paas-assessment-ajagu --resource-group rg-paas-assessment --slot staging
